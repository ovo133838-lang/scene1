# 第 1 题需求说明：小型电商的订单交易、发货与售前退款

版本：需求草案 0.1；日期：2026-11-11（北京时间）。当前阶段：需求分析，待学生审阅。仓库：[scene1](https://github.com/ovo133838-lang/scene1)。本文件中的 R、N、AC 等编号仅为本地追踪编号，不是飞书真实工作项 ID，也不能用于替代提交规范中的编号。

依据：[原始题集](../来源/Go项目业务场景题.md)的全部共通要求及题目 01、用户本轮提供的题面、用户对库存调整/退款重提/退款结果未知/截止边界/取消后迟到支付/商品变化后旧单履约六项问题的明确回答。来源岗位为题面所列北京易博中天相关岗位；这里的业务规模、金额及规则是教学设定，不是对该公司实际系统的描述。

## 1. 业务目标与完成含义

活动运营投放少量商品，三个预置买家购买，仓库负责人工登记发货，客服负责售前退款和异常支付。系统必须让不同角色使用同一组可追溯业务事实回答四个问题：

1. 买家：订单是否有效、支付是否被商城确认、能否取消或退款、钱退到哪里、运单是什么。
2. 仓库：当前订单是否确实具备发货资格，是否被退款流程冻结，是否已经发过货。
3. 客服：哪笔钱需要核实，哪次退款失败或结果未知，本次处理依据是什么。
4. 运营：商品还有多少可卖，哪些数量被订单占用或已经出库，实际确认收了多少钱、退了多少钱，还有哪些异常未解决。

本题的正常履约终点是登记发货；正常售前退款终点是渠道确认退款成功并释放相应库存；迟到收款处理终点是已关闭订单保持关闭且异常款项已核实退还。库存、款项、订单和异常记录必须能相互核对。

## 3. 角色、诉求与权限

| 角色 | 可以做什么 | 数据范围与限制 |
| --- | --- | --- |
| 买家 | 浏览在售商品；下单、进入模拟付款；查本人订单/收退款/运单；取消本人待付款订单；申请本人待发货订单整单退款 | 不查看或操作其他买家订单；不能决定订单金额、冒充员工、直接改支付或退款结果 |
| 运营 | 修改当前商品售价、上下架、调整可售数量；查询商品库存和跨订单交易核查 | 不通过商品修改影响旧订单快照；不直接改订单、伪造收款退款或处理状态 |
| 仓库 | 查询合法可发货订单；填写承运方和运单号；查必要履约信息 | 只在服务端确认待发货且无退款冻结时操作；不能审核退款或修改金额 |
| 客服 | 查看退款待审/失败/待确认和异常支付；同意或拒绝退款并说明原因；核实迟到支付；发起退款、查询结果或在明确失败后重试 | 不能把提交退款当成退款成功；不能直接改库存或伪造渠道结果；业务操作留人、时间和原因 |
| 模拟支付渠道 | 受理支付/退款，通过鉴权通知结果，提供可信状态查询 | 渠道凭证与用户凭证分离；通知须匹配订单、金额、渠道交易/退款标识；不得信任浏览器“支付成功”参数 |

## 5. 关键业务不变量

- 库存不为负，订单占用不超过可分配数量；同一订单的每次占用、释放及出库只生效一次。已付款待发货仍占货，退款审核/执行/失败/待确认期间继续占货。
- 旧订单金额始终等于下单单价快照 × 数量，后续价格变化、下架均不改写；本题不含运费与优惠。
- 同一渠道交易号只有一个归属；重复通知可留下接收轨迹，但不能增加真实收款、退款或库存变化。
- 发货与被受理的退款申请相互排斥。发货成功后退款申请失败；退款申请成功后发货失败，包括退款明确失败或结果未知期间。
- 同意退款、渠道接受请求、请求超时均不是退款成功。只有可信成功结果才能记成功退款；未知结果要先查明，不能把一次退款拆成两次实际退款。
- 已关闭订单不因迟到支付恢复；迟到款项退款成功不增加可售库存。已成功退款不能被重复、旧的失败回报倒退改写。
- 业务数据、失败原因、审核历史和异常证据持久化；不得以直接编辑最终状态代替真实处理过程。

## 6. 结果核查口径

库存核查以单个商品为单位：**初始可分配数量 + 运营调整净额 = 当前可售数量 + 活动订单占用数量 + 已发货数量**。活动占用包括待付款、已付款待发货以及未最终成功退款的正常售前退款订单。已关闭或已退款订单不占用；异常支付退款不产生库存变更。运营调整仅作用于可售部分，调整净额须可由流水重算。

资金核查：**已确认实收总额 − 已确认退款总额 = 当前净留存**。已确认实收包含正常有效支付和可信核实的迟到收款，后者不能被标作正常成交。退款申请、失败、待确认均不计成功退款。未经核实的验签失败/金额异常/未知订单通知按异常数量和金额提示单列，不直接当成已确认实收；若后续可信查询确认收款，再归入可追溯的异常收款，不自动给订单放行。

汇总必须支持下钻至交易/退款明细。净留存不是利润或已发货收入，本题不做完整财务记账。仍有未核实收款或退款待确认时，页面不能显示“异常全部处理完成”。
