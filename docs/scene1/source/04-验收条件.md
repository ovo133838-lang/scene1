# 第 1 题可验证验收条件

版本：需求草案 0.1；日期：2026-11-11（北京时间）。**本文件定义将来如何验证，所有条目当前均未执行。** A 项关联的规则需要先审阅确定。R/N 编号见[需求说明](01-需求说明.md)，U/A 见[假设清单](03-假设与确认清单.md)。

每次验证须保存：代码提交、测试数据、操作角色、实际步骤、服务端时间/教学时钟、请求标识、实际结果、数据库或查询结果、原始命令输出及证据路径。以下预期数值不是已运行结果。
