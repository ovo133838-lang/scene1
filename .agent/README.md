# Agent文件使用入口

用户所说“.agnet/agent文件”在本仓库以标准根AGENTS.md配合.agent目录实现。Codex可读取根AGENTS.md；.agent里的角色文件是项目约定，必须在对应独立会话开头明确读取，不假称工具会自动切换角色或启动测试。不要创建拼错的.agnet并声称自动生效。

- [开发Agent](development.md)：逐字段、接口、事务、页面、源码边界、自检与交接。
- [测试Agent](testing.md)：逐字段/接口、正常边界异常/权限幂等/并发恢复、覆盖率和缺陷复测。
- [验收Agent](acceptance.md)：原题全要求、独立上下文、版本/部署/过程/视频群门禁。
- [共享契约和审核入口](../docs/scene1/README.md)。

本次只是生成草案，尚未启动独立测试或验收，也未编写两个自编Skill。学生自行编写/审核的题面要求仍需真实完成；不得将AI起草说成学生已完成。后续每次加载记录日期、会话/任务、文件hash及代码版本。

推荐后续在已有或经用户授权创建的独立会话输入：先读取仓库AGENTS.md、.agent/<角色>.md、原题source/assignment.md及全部共享契约，锁定指定版本；按正式任务清单执行允许范围，保存实际输出，未运行不得判通过。不要在当前同一会话仅换称呼冒充独立上下文。
